# python-college-admission-eligibilty-checker
A beginner-friendly Python program that calculates your percentage and checks whether you are eligible to apply for college admission (60% minimum).

A simple command-line Python program that calculates a student's percentage
from their marks and tells them whether they are eligible to apply for
admission in a college.

## Features
- Takes obtained marks and total marks as input
- Calculates the percentage (shown to 2 decimal places)
- Checks eligibility against a minimum of **60%**
- Prints a clear message: eligible or not eligible

## How It Works
1. Enter the marks you obtained.
2. Enter the total marks.
3. The program calculates: `percentage = (marks / total_marks) * 100`
4. If the percentage is **60 or above**, you are eligible to apply.
## Example Output
```
Enter the marks obtained: 850
Enter the total marks: 1100
Your percentage is: 77.27%
Congratulations! You are eligible to apply for admission in the college.
```

```
Enter the marks obtained: 500
Enter the total marks: 1100
Your percentage is: 45.45%
Sorry, you are not eligible to apply for admission in the college.
```
